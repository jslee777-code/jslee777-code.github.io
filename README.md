# Research Portfolio — GitHub Pages

Static multi-page academic portfolio.

## Deploy
1. Open repository `jslee777-code.github.io` in GitHub.
2. Upload **the contents** of this folder (not the folder itself) to the repository root. Preserve `projects/` and `assets/` subdirectories.
3. Commit changes to `main`.
4. Under Settings → Pages, choose **Deploy from a branch**, `main`, `/ (root)`.
5. Open https://jslee777-code.github.io/ after deployment.

## Edit
- Homepage: `index.html`
- Shared design: `style.css`
- Project descriptions: `projects.html`, `research.html`, and `projects/*.html`
- Publications: `publications.html`
- CV: `cv.html`

Replace placeholders with verified research details and your own figures. No external libraries or services are required.
